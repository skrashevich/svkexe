$ ssh svkexe-demo "help new"

  new <name> [--cpu=N] [--memory=MB] [--disk=GB] [--task="..."]
  Creates a VM from the platform base image, starts it and installs the agent. Without the resource flags it gets 2 cores, 2048 MB of RAM and 10 GB of disk. A task given here is handed to the agent once the VM is up.

  Arguments:
    name           VM name: 2-63 lowercase letters, digits and hyphens; it becomes the VM's hostname

  Flags:
    --cpu=...      CPU cores
    --memory=...   memory in MB
    --disk=...     disk in GB
    --task=...     task handed to the agent on first boot

  Examples:
    new dev
    new dev --cpu=4 --memory=4096 --task="set up a Go project"
